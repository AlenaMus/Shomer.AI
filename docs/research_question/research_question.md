# Shomer.AI — שאלת המחקר (מותאמת לפרויקט)

**סטטוס:** עודכן 2026-05-27 — **שאלת מחקר מחודשת** (החלפה מהציר הרב-מודאלי לציר ההקשר השיחתי). ראו `../plan-docs/decisions/research-framing.decision.md` (החלטה D-Reframe-2026-05-27).
**מקור הבחירה:** דיון 2026-05-27 — אלונה בחרה את אופציה א' (הקשר ↔ false positives) כשאלה הראשית.
**דדליין הגשה:** מפגש 3 — 28/05/2026.

---

## שאלת המחקר הראשית

> **עד כמה הוספת ההקשר השיחתי (ההודעות הקודמות בשרשור) לסיווג בריונות בעברית מפחיתה את שיעור ההתרעות-שווא (false positives), לעומת סיווג ההודעה הבודדת במנותק — מבלי לפגוע ב-recall?**

**הבעיה האמיתית שהשאלה תוקפת:** המערכת "עושה הנחות על בסיס המידע כמו שהוא", בלי להבין את הקשר השיחה — ולכן מתריעה שווא על הודעות שנראות פוגעניות אך תמימות בהקשרן (סרקזם, הקנטה ידידותית, ציטוט), ומפספסת בריונות שמתבררת רק לאור התורים הקודמים.

הניסוח עומד בדרישת שקופית 7 של ד"ר סגל: מוגדר *מה נמדד* (FPR + recall), *מול מה משווים* (אותו מודל ללא הקשר), ו*מה נחשב הצלחה* (ירידת FPR מובהקת עם recall לא-נחות).

### הניסוח המדויק (לתזה)
על דאטהסט שיחות עברי (סינתטי לאימון + gold set אמיתי קטן להערכה), משווים את אותו מסווג בשני תנאים — **context-blind** (הודעה בודדת) מול **context-aware** (הודעה + k התורים הקודמים) — ומודדים את הפרש ה-FPR וה-recall, בדגש על מקרי "היפוך-הקשר".

## איך הפרויקט עונה על השאלה

| רכיב בשאלה | איך Shomer.AI מספק אותו |
|---|---|
| שני התנאים (blind / aware) | אותו מודל QLoRA-fine-tuned, פעמיים: עם prompt של הודעה בודדת, ועם prompt שכולל k תורים קודמים |
| דאטה שיחתי בעברית | **סינתזה** של שיחות מתויגות (מפגש 6) — אין קורפוס עברי קיים. כולל מקרי היפוך-הקשר מכוונים. תקדים: SynBullying, ToxiGen |
| הערכה אמינה | **gold set אמיתי** של ~100–200 קטעי שיחה עברית, מתויג ידנית. **מאמנים על סינתטי, מודדים על אמיתי.** |
| מדידה | FPR, precision, recall, macro-F1 — לכל תנאי, עם מבחן מובהקות על הפרש ה-FPR |
| הסבר ("למה") | ניתוח שגיאות: באילו סוגי מקרים ההקשר מתקן התרעת-שווא (סרקזם / הקנטה תוך-קבוצתית / התייחסות לתור קודם) |

## תת-שאלות

1. **יסוד (RQ1, נשמר):** עד כמה מודל QLoRA fine-tuned 7B עברי מסווג בריונות, לעומת zero-shot prompting על אותו מודל בסיס?
2. **אופציונלי / הרחבה (היה אופציה ב' — סומן ע"י אלונה כמורכב):** מהו ה-Pareto frontier בין precision (FP) ל-recall כפונקציה של גודל ההקשר *k* (כמה תורים אחורה)?
3. **אופציונלי / הרחבה (היה אופציה ג' — סומן ע"י אלונה כמורכב):** באילו סוגי מקרים בלשניים (סרקזם, אירוניה, הקנטה תוך-קבוצתית) ההקשר מתקן התרעות-שווא, ובאילו לא?
4. **משני (ציר רב-מודאלי — ירד מ"ראשי"):** כשהשיחה כוללת תמונה, איזו אסטרטגיית טיפול בתמונה תורמת לסיווג? (נשמר כמסלול אופציונלי; הכרעה במפגש 4.)

## השערות (מדידות)

- **H1:** סיווג context-aware יפחית את ה-FPR ב-≥ X נקודות אחוז לעומת context-blind, **מבלי** להוריד את ה-recall ביותר מ-Y נקודות. *(לקבע X, Y לפני מפגש 8.)*
- **H2:** עיקר הפחתת ה-FPR מרוכז במקרי **"היפוך-הקשר"** — הודעות שנראות פוגעניות במנותק אך תמימות בהקשרן.
- **H3 (יסוד):** QLoRA fine-tune ינצח zero-shot ב-macro-F1 על משימת הבסיס (RQ1).

---

## מדדים, baseline והגדרת הצלחה

- **מדד ראשי:** שיעור התרעות-שווא (**FPR**) — וההפרש בינו בין שני התנאים. **מדד שמירה:** recall (אסור לרדת מהותית). **מדדי-על:** precision, macro-F1.
- **Baseline (התנאי המושווה):** סיווג **context-blind** — אותו מודל בדיוק, על ההודעה הבודדת בלבד. (ועוד baseline-יסוד: zero-shot, ל-RQ1.)
- **הצלחה:** ירידה **מובהקת סטטיסטית** ב-FPR במעבר ל-context-aware, עם recall לא-נחות (non-inferiority), מוכחת על gold set אמיתי וניתנת לשחזור מ-GitHub.
