## 6. Defects / follow-ups

1. **PowerShell 5.1 lacks `Invoke-WebRequest -Form`.** First multipart attempt failed; had to switch to `curl.exe`. Not a project bug, but the test plan should explicitly recommend `curl.exe` over `Invoke-WebRequest` for multipart. *Action:* update the test plan's PowerShell snippets to use `curl.exe` for multipart, like the `curl.exe -F "image=@..."` example. (Severity: low. Doesn't affect Pass/Fail.)
2. **Server `--host` differs between runs.** This server-side run bound to `127.0.0.1`. The Android run needs `0.0.0.0`. The test plan currently says `0.0.0.0`; this run deviated for convenience. *Action:* none — Android run will restart with the correct bind.
3. **`latency_ms` in stub responses is 0.** Mathematically correct (stub does no work), but if downstream code asserts `latency_ms > 0`, it'd fail. Acceptable for Phase 1; revisit in Phase 2 when real backends fill it in.
