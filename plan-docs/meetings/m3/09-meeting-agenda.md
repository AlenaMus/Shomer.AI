# משימה 9 — דף סדר-יום ושאלות/הכרעות (Meeting Agenda)

**מפגש:** 3 (28/05/2026) · **עדיפות:** נמוכה · **הערכת זמן:** 0.5 שעה · **תאריך יעד:** 27/05 · **תלוי ב:** —
**מקור:** [`../../docs/next-meeting-prep-2026-05-28.md`](../../docs/next-meeting-prep-2026-05-28.md)

## מטרה
להכין דף אחד לסדר-יום המפגש + שאלות פתוחות + הכרעות (פתוח על המסך / מודפס), כדי שהמפגש יהיה יעיל.

## צעדים
- להעתיק מתוך מסמך ההכנה את: סדר היום (45 דק׳), 3 השאלות הפתוחות, ו-2 ההכרעות (בפורמט 3-אופציות + המלצה).
- לוודא שהמרצה הופך מ"בוחן" ל"יועץ" — מגיעים עם המלצה, לא עם שאלה פתוחה.

## תוצר
`docs/meeting-03-agenda.md` (או דף מודפס).

## הגדרת "בוצע"
- [ ] סדר יום עם חלוקת זמן.
- [ ] 3 שאלות + 2 הכרעות מוכנות להצגה.
- [ ] מודפס / פתוח במסך לפני המפגש.
