# משימה T1 — יצירת 1000 משפטים ב-4 סגנונות

**מפגש:** 5 (04/06/2026) · **עדיפות:** גבוהה · **הערכת זמן:** 3.0 שעות · **תאריך יעד:** 31/05 · **תלוי ב:** T0

## מטרה

ליצור קורפוס בדיקה של 1000 משפטים עבריים המייצגים את סוגי הטקסט שיגיעו בפועל מצ'אט ילדים — כקלט ל-OCR.

## 4 הסגנונות (250 כל אחד)

| סגנון | תיאור | דוגמה |
|---|---|---|
| **A — עברית ברורה** | פורמלי, כתיב/דקדוק נכון | "היום למדנו על הגיאוגרפיה של ישראל." |
| **B — עברית ילדים** | גיל 8–14, 10–15% שגיאות | "אנחנו הלכנו לגנ ציבורי ושחקנו כדורגל בשביל מלא זמן" |
| **C — קוד-סוויצ'ינג** | WhatsApp ישראלי, ערבוב אנגלית | "אני so done עם בית הספר היום literally לא יכולה" |
| **D — עברית עם כתיב לקוי** *(אנלפביתי, דובר ילידי)* | דובר עברית ילידי שכותב פונטית עם 25–35% שגיאות כתיב שיטתיות (ש↔ס · ח↔כ · ק↔כ · ה↔א). דקדוק תקין. | "באלי לאחול פיזה" (`בא לי לאכול פיצה`) |

**תחום התוכן:** חיי בית-ספר, חברות, משחקים, רגשות. ללא תוכן פוגעני.

## צעדים

1. לכתוב `scripts/ocr_validation/01_generate_sentences.py`.
2. לכל סגנון — ליצור prompt עם הוראות מפורטות ל-LLM (GPT-4o-mini) לייצר 250 משפטים.
3. לשמור כ-`data/ocr_validation/sentences.jsonl` — כל שורה: `{id, style, text, style_label}`.
4. לאמת: ספירת רשומות, ייחודיות, ויזואליזציה של 5 דגימות לכל סגנון.

## תוצר

`scripts/ocr_validation/01_generate_sentences.py` + `data/ocr_validation/sentences.jsonl` (1000 רשומות)

## הגדרת "בוצע"

- [ ] `sentences.jsonl` מכיל בדיוק 1000 רשומות
- [ ] 250 רשומות לכל סגנון (A/B/C/D)
- [ ] סגנון B: בדיקת ספוט מאשרת 10–15% שגיאות (10 דגימות ידניות)
- [ ] סגנון C: כל רשומה מכילה לפחות מילה אנגלית אחת בתוך טקסט עברי
- [ ] סגנון D: כל רשומה מכילה לפחות שגיאה אחת של דובר לא-ילידי
- [ ] אין כפילויות (assert ייחודיות בסקריפט)
- [ ] ייצור חוזר (random seed מתועד בסקריפט)

## הערת עלות

~1000 משפטים × ~50 טוקן = ~50K טוקן קלט + פלט ≈ $0.05 (GPT-4o-mini). אם API לא זמין — fallback rule-based (הזרקת שגיאות לפי חוקים מוגדרים).
