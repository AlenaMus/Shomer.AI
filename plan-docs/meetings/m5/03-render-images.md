# משימה T2 — רנדור 1000 תמונות PNG (בועות צ'אט)

**מפגש:** 5 (04/06/2026) · **עדיפות:** גבוהה · **הערכת זמן:** 3.5 שעות · **תאריך יעד:** 01/06 · **תלוי ב:** T1

## מטרה

להמיר כל משפט מ-`sentences.jsonl` לתמונת PNG שנראית כמו צילום מסך אמיתי מצ'אט — כך ש-Tesseract נתקל בתנאים דומים לשימוש אמיתי.

## דרישות טכניות לתמונה

| פרמטר | ערך |
|---|---|
| גודל | ~480×80–160px (תלוי באורך הטקסט) |
| רקע | ירוק WhatsApp (#ECE5DD) |
| בועה | לבנה, פינות מעוגלות |
| גופן | David / Arial Unicode / Segoe UI (עברית RTL) |
| כיוון טקסט | RTL (ימין לשמאל) |
| רעש | דחיסת JPEG אקראית (איכות 72–88) + Gaussian noise קל (sigma 0–1.5) |
| שמירה | PNG (אחרי הוספת noise) |

## צעדים

1. לכתוב `scripts/ocr_validation/02_render_images.py`.
2. לוודא שהגופן שנבחר תומך בעברית (fail-fast אם לא).
3. לשמור בתיקיות: `data/ocr_validation/images/{style_label}/{id}.png`.
4. לוודא שכל תמונה > 1KB (תמונה ריקה = שגיאה).
5. להדפיס: שם הגופן שנבחר + מספר תמונות שנוצרו לכל סגנון.

## תוצר

`scripts/ocr_validation/02_render_images.py` + `data/ocr_validation/images/` (4 תיקיות, 1000 קבצי PNG)

## הגדרת "בוצע"

- [ ] 1000 קבצי PNG קיימים, 250 לכל תיקייה
- [ ] בדיקת ספוט ידנית: עברית מוצגת RTL ב-10 דגימות אקראיות
- [ ] אין תמונות שבורות/ריקות (assert > 1KB)
- [ ] artifacts של JPEG נראים אך הטקסט קריא בזום 100%
- [ ] הסקריפט מדפיס שם הגופן שבשימוש (ללא fallback שקט לגופן לא-עברי)
- [ ] התמונות נראות כמו צ'אט — לא טקסט על רקע לבן

## סיכון עיקרי

אם Pillow לא מוצאת גופן עברי — מציגה ריבועים ● במקום אותיות. הסקריפט חייב לזהות זאת ולעצור עם הודעה ברורה (לא להמשיך ולייצר 1000 תמונות שבורות).
