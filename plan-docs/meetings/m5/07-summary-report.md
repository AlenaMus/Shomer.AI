# משימה T6 — כתיבת דו"ח סיכום (עברית RTL)

**מפגש:** 5 (04/06/2026) · **עדיפות:** גבוהה · **הערכת זמן:** 2.0 שעות · **תאריך יעד:** 03/06 · **תלוי ב:** T5

## מטרה

לכתוב דו"ח מסכם בעברית המציג את ממצאי אימות ה-OCR לד"ר סגל במפגש 5. הדו"ח ישמש כראיה שהצוות לא "התקדם בעיוורון" — הוא נעצר, מדד, והחליט על בסיס נתונים.

## מבנה 7 חלקים (חובה)

1. **רקע** — מדוע אימתנו OCR לפני פיין-טון DictaBERT
2. **מתודולוגיה** — 4 סגנונות, 1000 תמונות, 3 מטריקות, סף 15%
3. **תוצאות** — טבלת mean CER / WER / cosine לכל סגנון
4. **ממצא מרכזי** — אילו סגנונות עוברים, אילו נכשלים
5. **פסיקה** — Tesseract עובר / נכשל (verdict ברור, מבוסס נתונים)
6. **המלצה** — להמשיך עם Tesseract / לעבור ל-EasyOCR / לתכנן MLKit (כולל הערכת מאמץ)
7. **צעדים הבאים** — מה קורה עכשיו
