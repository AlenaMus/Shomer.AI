**מקור אנגלי מפורט:** [`plan/01-research-foundation.md`](../plan-docs/plan/01-research-foundation.md)

---

## מטרה

לנעול את נושא הפרויקט מול ד"ר סגל עם הוכחה שהוא עומד במסגרת VALID המלאה — ולצאת עם ריפו GitHub פעיל, README מקצועי, שאלת מחקר חדה, ו-prompt book מוכן לרישום.

---

## דרישות ד"ר סגל למפגש זה

- **VALID:** ערך ממשי (Value), ליבת AI (AI-Core), קשור לקורס (Learned), חדשני (Innovative), ניתן לביצוע בסקופ (Doable).
- GitHub פעיל מהיום הראשון: commits משמעותיים, README מקצועי, מבנה תיקיות (`src/`, `docs/`, `tests/`, `notebooks/`, `results/`, `assets/`, `config/`).
- Prompt book — מוכן מהיום הראשון עם 7 שדות: Goal, Context, Prompt (גרסה מדויקת), Model (+settings), Output (בפועל), Evaluation (איכות + עלות), Decision (קבל/תקן).
- PRD skeleton — עבור כל אלגוריתם מרכזי: Purpose, Inputs, Outputs, Metrics, Risks, Tests.
- שאלת מחקר מדידה: מה נמדד, מה ה-baseline, מה = הצלחה.
- חוק הזהב — סוכני AI חובה: לתכנן כבר עכשיו האם Path A (Claude Code כלי פיתוח) ו/או Path B (סוכן במוצר).

---

## איך Shomer.AI עונה על הדרישה

- **VALID:** כפי שמופיע ב-`01-research-foundation` — Shomer.AI = ערך להורים (V), ליבה היא מודל fine-tuned + image routing (A), קשור ל-NLP/Agents (L), חידוש = multimodal Hebrew (I), POC הוכיח Doable (D).
- **GitHub:** הריפו קיים עם היסטוריית git ממיגרציה מ-offensive-hebrew. צריך להוסיף מבנה תיקיות סגל-תואם.
- **Prompt book:** `docs/prompt_book.md` נוצר כבר ב-01 — צריך להפוך לפורמט 7 שדות.
- **שאלת מחקר:** `research_questions.he.md` — 8 RQs מנוסחות, ציר התזה = RQ3 + RQ4 (multimodal routing).
