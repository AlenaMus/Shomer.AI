# פגישה 2 — שאלת מחקר

**שלב:** A · מחקר | **מיקוד קורס:** Literature + Baseline
**מקור אנגלי מפורט:** [`plan/02-literature-and-baseline.md`](../plan-docs/plan/02-literature-and-baseline.md)

---

## מטרה

לבנות ספריית ספרות אמיתית (15–20 מקורות, 2 anchor papers), להוריד datasets, ולכתוב baseline ראשון — לא כדי להיות טוב, אלא כדי לקבל מספר להכות. היציאה ממפגש זה: "Anchor papers הגיעו ל-X; אני מכוונת ל-Y בעזרת Z."

---

## דרישות ד"ר סגל למפגש זה

- **Literature funnel:** 15–20 מקורות → 5–8 core → 2 anchor papers → baseline.
- **שאלת מחקר מדידה:** מה נמדד (metric), מה ה-baseline, מה = הצלחה — הכול מספרי ומוגדר.
- **Baseline ספציפי:** F1 מדויק (לא "כ-70%"), מתועד ב-GitHub.
- **EDA:** label balance, text lengths, examples per category.
- **Preparatory report v0.1** — תחילת תשובות לשאלות השקופיות של סגל.
- **Prompt book:** לרשום כל קריאת LLM משמעותית (סיכום מאמר, שאלה לClaude) עם 7 שדות.

---

## איך Shomer.AI עונה על הדרישה

- **2 anchor papers:** כפי שמופיע ב-`related_work.he.md` — SinaLab Offensive-Hebrew (dataset + task) + QLoRA (Dettmers et al., 2023, NeurIPS) — שני צירי התרומה.
- **Dataset:** SinaLab/Offensive-Hebrew ב-HuggingFace — 5 קטגוריות: `abusive | hate | violence | pornographic | non_offensive`.
- **Baseline:** `02-literature-and-baseline` מגדיר TF-IDF + Logistic Regression על OffensiveHebrew, macro-F1 מספרי.
- **EDA:** `notebooks/01_eda.ipynb` — balance, lengths, examples per category.
- **RQs:** `research_questions.he.md` — 8 שאלות, RQ1+RQ2 נענות בפגישה 5, RQ3+RQ4 = עמוד שדרה.

---

## פערים ודגשים

- **Gap שמה:** `02-literature-and-baseline` טוב; אין פערים מבניים.
- **ציטוט SinaLab:** לאמת את הציטוט המדויק של מאמר SinaLab (לא רק dataset card) לפני פגישה 2.
- **Davidson English baseline:** להוסיף כנקודת השוואה חוצת-שפות (כפי שמופיע ב-`02`).
- **Prompt book entries:** כל שאלה לClaude Code על סיכום מאמר — רשומה בפורמט 7 שדות.
