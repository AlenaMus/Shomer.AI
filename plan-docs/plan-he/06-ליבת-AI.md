# פגישה 6 — ליבת AI

**שלב:** C · פיתוח | **מיקוד קורס:** Models + RAG (+ Synthetic Data)
**מקור אנגלי מפורט:** [`plan/06-synthetic-data.md`](../plan-docs/plan/06-synthetic-data.md) + [`plan/07-agents-and-rag.md`](../plan-docs/plan/07-agents-and-rag.md)

---

## מטרה

לבנות את ליבת ה-AI: נתונים סינתטיים לסגירת פער ה-slang העברי, image backends (OCR + vision), context/alert logic, ו-pipeline מקצה לקצה. זה המפגש שמרכיב את כל רכיבי ה-AI יחד.

---

## דרישות ד"ר סגל למפגש זה

- **בחירת מודל — decision matrix:** Cost/Quality/Latency/Risk/Best-use — מוכח עם measured logs.
- **RAG / retrieval:** אם השימוש הוחלט ב-meeting 4 — knowledge base + retrieval לאזהרות הורה.
- **Synthetic data:** תיעוד מלא של prompt book לכל generator strategy.
- **סוכנים — כלל 2:** כל סוכן מתועד (tools, boundaries, prompts, memory, permissions, stop conditions).
- **Token cost measured:** לא תיאורטי — לרשום logs אמיתיים.

---

## איך Shomer.AI עונה על הדרישה

- **Synthetic data:** `06-synthetic-data` — 4 strategies (zero-shot, few-shot seeded, adversarial, back-translation), 2,500 דוגמאות, `data/synthetic/v1.jsonl`.
- **Image backends:** `07-agents-and-rag` — OCR (Tesseract `heb`) + vision (Ollama `qwen2.5vl:7b` — ללא מקף!) + strategy router (`ocr_only / vision_only / pipeline / parallel`). **שם מודל חשוב: `qwen2.5vl:7b` ולא `qwen2-vl:7b`.**
- **Context/Alert:** LLM validates yellow/red flags → 3 severity levels, parent-friendly text.
- **RAG (אם נבחר):** knowledge base + ChromaDB לחומרי hotline.

---

## פערים ודגשים

- **חישוב עלות token אמיתי:** כל קריאה ל-LLM חיצוני (context/alert step) — לרשום ב-logs כמות tokens בפועל.
- **Prompt book:** ≥ 15 רשומות מ-generator (goal/model/result/decision) + רשומות ל-context/alert prompts.
- **Ablation study:** v1 (ללא synth) vs v2 (עם synth) על original + slang test sets — `results/ablation_study.png`.
- **Slang gap:** מטרה = +5pp F1 על slang test set; לתעד "2,000 דוגמאות סינתטיות הרימו F1 ב-X% תמורת $Y."
- **Router PRD:** ה-strategy router הוא בעצם תכנון הסוכן (RQ3 מ-`research_questions.he.md`) — לתעד כ-agent component.
