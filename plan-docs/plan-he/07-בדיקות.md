# פגישה 7 — בדיקות

**שלב:** C · פיתוח | **מיקוד קורס:** Coverage + Cost + Gold Set + Metrics
**מקור אנגלי מפורט:** [`plan/08-gold-set-and-metrics.md`](../plan-docs/plan/08-gold-set-and-metrics.md)

---

## מטרה

ראיות, לא תחושות. לבנות gold set מסומן ידנית (300–500 דוגמאות), להריץ את המערכת המלאה עליו, לקבל metrics סופיים (F1, FPR, latency, cost), ולתקן 3–5 הבעיות הגרועות ביותר. זה גם המפגש שבו image-strategy study (RQ3+RQ4) מקבל את מספריו.

---

## דרישות ד"ר סגל למפגש זה

- **4 גרפים חובה:** (1) Baseline comparison, (2) Model benchmark, (3) Sensitivity analysis, (4) Flagship-paper gap.
- **Coverage + Cost:** pytest coverage, edge cases, מדידת עלות token בפועל, model benchmark.
- **Code quality gate:** Ruff, pytest, docstrings, secrets ב-`.env`, green CI.
- **"אם אין ראיה ב-GitHub — זה לא הוכח":** כל metric = metric definition + data source + calc method + reproducible script.
- **Cohen's Kappa:** inter-annotator agreement ≥ 0.65.

---

## איך Shomer.AI עונה על הדרישה

- **Gold set:** כפי שמופיע ב-`08-gold-set-and-metrics` — 3 labellers, Kappa, 300–500 examples מפורומים ישראלים/Reddit.
- **4 גרפים:** `08` מגדיר במפורש:
  - `results/baseline_comparison.png` — TF-IDF baseline vs fine-tuned model.
  - `results/model_benchmark.png` — השוואת strategies / model variants.
  - `results/sensitivity.png` — short/long/emoji/mixed-language inputs.
  - `results/flagship_comparison.png` — מול SinaLab anchor paper.
- **Image strategy study (RQ3+RQ4):** `POC_Plan.md` Phase 4 — A/B על image buckets, per-strategy F1.

## פערים ודגשים

- **מיפוי מחדש קריטי:** ב-`Plan.md` המקורי, gold set + metrics היו בפגישה 8, ופגישה 8 הייתה "video". לפי ד"ר סגל: **dev = meetings 5–7, video = meeting 8**. לכן **gold set + metrics עוברים לכאן (פגישה 7)**.
- **Image labelling:** ~100–200 תמונות מתויגות ידנית עבור image-strategy study — כפי שמוגדר ב-`research_questions.he.md` RQ3.
- **Sensitivity לעברית:** inputs מיוחדים: RTL, ניקוד, code-switching עברית-אנגלית, סרקזם.
- **כל גרף — reproducible script:** `results/plot_baseline.py` וכו' — לא Jupyter notebook בלבד.
- **`ruff check src/` + `pytest --cov` ירוקים לפני tag.**
