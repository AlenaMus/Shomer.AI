# Meeting 10 — Defense & Final Submission

**Phase:** D · Presentation · **Status:** ⬜ not started · **Source:** `Shomer_AI_10_Meeting_Plan` §10

## 🎯 Goal
Deliver a professional 10–15 min defense + Q&A, show a working product, and submit a portfolio you
can show to employers.

## 📋 Before (final week)
- Full clean run: `git clone` on a fresh machine, run from zero, confirm everything works.
- Prepare answers to the 20 most likely questions.
- Rehearse the talk against a mirror / friend at least 3 times.

## ⚙️ Steps
| # | Action | Output |
|---|--------|--------|
| 10.1 | Q&A prep: 20 likely questions with structured answers | `docs/qa_prep.md` |
| 10.2 | Clean run: fresh clone, install per README, prove reproducibility | reproducibility proof |
| 10.3 | Timed rehearsals (open 60 s, demo 4 min, evidence 2 min) | timed defense |
| 10.4 | Submission checklist (README, demo, video, deck, report, prompt book, code, tests, metrics) | `docs/submission_checklist.md` |
| 10.5 | Backup plans: 3 demo levels (live / recorded / screenshots), power + hotspot | risk mitigation |
| 10.6 | **Defense day**: open → live demo → GitHub evidence → results → Q&A | grade |
| 10.7 | Final submission: tag `v1.0-final`, GitHub release, send report + video + repo URL | official submission |

## 📦 Final deliverables
Tagged repo (code, docs, results, prompts, decisions), final report PDF, defense deck, promo video, full prompt book, all charts, runnable demo.

## ✅ Done when
- An outsider can clone, follow the README, install, and run with no help.
- Every claim in the deck is backed by a file / commit / chart.
- 3 demo backup levels ready. Tag **v1.0-final** pushed.

## ⚠️ Risks (defense day)
- Live demo fails (API/internet) → warm up beforehand; switch to the recorded backup calmly.
- Unknown question → answer honestly: "Good point — out of scope for the time I had, but I'd approach it like this…"
- Over time → keep an eye on the clock; cut the demo before cutting Q&A.
