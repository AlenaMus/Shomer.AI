### 5. Analyze flow → design context↔FP test scenarios tied to the research question

**Prompt (restated):** Analyze the existing project flow and prepare test scenarios tied to the research
question — to prove how context reduces false positives. Also check the literature flagship: how can our
project contribute to it, and what tests prove what we should do?

**Delivered:**
- **Flow analysis:** traced `classifier → triage → context_agent`. Key structural finding — the DictaBERT
  classifier is **context-blind by construction**; *all* context enters only at the Context Agent, and the
  RQ's two arms are **already wired** as the `CONTEXT_AGENT_ENABLED` A/B switch in `triage/settings.py`.
  Audit store already pre-exposes `query_for_evaluation()` + `set_gold_label()` ("Meeting-8 ΔFPR harness").
- **Three methodological findings** surfaced: (F1) context only acts inside the borderline band [0.3,0.7],
  so the *product* A/B under-measures the true effect — science run must route the whole gold set through
  the CA; (F2) the clean scientific baseline is the *same LLM judge, history empty vs populated*
  (`build_user_prompt` already takes history as a param) — isolates context as the only variable; (F3)
  paired design ⇒ **McNemar**, not a two-sample test.
- **Test-scenario matrix (3 categories):** A = context *repairs* FP (headline, drives ΔFPR), B = context
  *reveals* TP (recall guard), C = context-*invariant* controls (specificity). Decomposition maps to
  H1/H2 and blocks the "trust-everything" degenerate strategy.
- **6 experiments E1–E6** with what each proves; **E6 (selective-agent vs naive-concat)** = the literature
  contribution that answers Pavlopoulos's open "how to use context efficiently" question in Hebrew.
- **Flagship contribution map:** SinaLab (we add the conversational layer to their blind baseline) ·
  Pavlopoulos (selective > naive concat) · Sap/Davidson (quantify FP correction in Hebrew) · SynBullying
  (reusable Hebrew context-flip set) · Synthetic-vs-Gold (train-synth / eval-real).
- **Seed gold set:** 22 hand-written Hebrew items across A/B/C with `isolated_appearance` + bilingual
  rationale — bootstrap for the ~150–200-item gold set.

**Files:** [`docs/research_question/context_fp_test_plan.md`](../docs/research_question/context_fp_test_plan.md) (new),
[`data/gold/context_eval_seed.jsonl`](../data/gold/context_eval_seed.jsonl) (new).

**Open question for Alona (pre-registration, blocks the run):** lock **X** (min FPR drop, proposed ≥10pp),
**Y** (max recall loss, proposed ≤3pp), **k** (context window, proposed 5), **α**=0.05 — *before* running,
to avoid p-hacking. Then capture in `plan-docs/decisions/context-fp-experiment.decision.md`.
